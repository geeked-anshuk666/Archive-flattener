# Security Policy

## Supported Versions

Currently, only the latest version of Archive Flattener receives security updates.

---

## Reporting a Vulnerability

Please do not create a public GitHub issue for security vulnerabilities.

Instead, contact the repository owner privately and include:

- Description of the issue
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Suggested mitigation (optional)

Reports will be reviewed as quickly as possible.
