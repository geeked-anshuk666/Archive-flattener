# Code of Conduct

## Our Pledge

We are committed to creating a welcoming, respectful, and inclusive environment for everyone participating in this project.

---

## Expected Behavior

- Be respectful.
- Provide constructive feedback.
- Help others learn.
- Be professional during discussions.
- Respect differing viewpoints.

---

## Unacceptable Behavior

Examples include:

- Harassment
- Hate speech
- Personal attacks
- Trolling
- Spam
- Publishing private information

---

## Enforcement

Project maintainers reserve the right to edit or remove comments, issues, pull requests, or other contributions that violate this Code of Conduct.
